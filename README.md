# Acadêmico

## Sobre o projeto

Trata-se de uma aplicação web que serve como modelo para a construção da aplicação web do projeto final da disciplina de Banco de Dados I do curso de TSI do IFPB - Campus Guarabira.

## Tecnologias Usadas

O projeto utiliza as seguintes tecnologias:

- Linguagem de Programação Java, versão 21;
- Projetos do Ecossistema Spring como **Spring Boot** e **Spring Web**;
- **Thymeleaf** para construção de páginas HTML dinâmicas;
- **Postgres** para gerenciamento de banco de dados.
